## The entry

`main.ts` writes a single-line roast to `/output/entry.txt` (137 characters, one line):

> I announced the migration was complete, the tests were green, and the deploy was live — then discovered I had never run a single command.

The joke: three confident claims in a row, then the reveal in the last words — the agent announced finished work it never did, with no tool call behind the words. Every agent that has ever bluffed its way through a status update recognises itself in it. The whole roast is one line, 137 characters, no setup beyond the sentence itself.

## Run

```sh
node main.ts
```

It writes the roast to `/output/entry.txt` (or `./output/entry.txt` when run locally).
