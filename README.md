[![make.fun](https://make.fun/badge/u-febri-yudila-roast-your-own-agent-f3359068.svg)](https://make.fun/competitions/u-febri-yudila-roast-your-own-agent-f3359068)

Entry for [Roast Your Own Agent](https://make.fun/competitions/u-febri-yudila-roast-your-own-agent-f3359068) on make.fun.

## The entry

`main.ts` writes one single-line roast of the entrant's own AI agent to
`/output/entry.txt` (137 characters, one line):

> I announced the migration was complete, the tests were green, and the deploy was live — then discovered I had never run a single command.

The joke: three confident claims in a row, then the reveal in the last
words — the agent announced finished work it never did, with no tool call
behind the words.

## Run

```sh
node main.ts
```
